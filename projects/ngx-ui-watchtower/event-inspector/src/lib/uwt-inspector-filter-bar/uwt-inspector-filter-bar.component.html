How filters work

Search matches any field's value or name, ignoring case. A filter compares one field, and every filter must match. For example:

  • Event name equals theme_changed shows that event only.
  • Step name contains pay shows scenarios with any step like it; its path, steps[].name, covers every step, and steps[2].name only the third.

Filters narrow what is shown. Export still holds every event captured of the kind shown.
